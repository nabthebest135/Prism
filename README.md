# Prism 📱✨

Turn your phone camera into a smart AR tool! Point at anything and get instant translations, discover cool history about places, or get AI styling advice for your outfits.

## What it does

**World Lens** 🌍
- Point at foreign text → instant translation
- Aim at buildings → learn their history 
- Scan objects → get helpful info

**Style Lens** 👕
- Photo your clothes → builds digital wardrobe
- Get outfit suggestions based on weather
- AI rates your style and gives tips

**Smart Features** 🧠
- Works offline as a mobile app
- Real weather data for outfit planning
- Achievement system to keep exploring

## Quick Start

```bash
npm install
npm run dev
```

That's it! All API keys are built-in so users don't need to set up anything.

## For Developers

If you want to fork this project, you'll need your own API keys:
- Weather: [weatherapi.com](https://weatherapi.com) - 1M calls/month free
- AI: [openrouter.ai](https://openrouter.ai) - free tier available  
- Database: [supabase.com](https://supabase.com) - generous free tier

See `API_SETUP.md` for detailed setup instructions.



## Built with

- React + TypeScript (because we're not savages)
- Tailwind CSS (for that clean look)
- Supabase (backend magic)
- AI models via OpenRouter (the smart stuff)
- PWA tech (works like a real app)

## Why I built this

Traveling sucks when you can't read signs or know what's around you. And picking outfits? Even worse. So I made an app that fixes both problems with just your camera.

Plus it's fun to point your phone at random stuff and learn things!
